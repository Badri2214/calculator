# calculator12
🧮 Simple Calculator

A simple web-based calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, division, and modulus.

## 🚀 Features  
- Enter two numbers and perform calculations.  
- Supports:  
  - Addition ➕  
  - Subtraction ➖  
  - Multiplication ✖️  
  - Division ➗  
  - Modulus %  
- Displays results instantly.  
- User-friendly interface.
